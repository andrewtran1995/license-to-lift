# Text-style prototype (throwaway)

**Question:** how should License to Lift's text look: casing, and which typeface?

**Round 1, casing** (A caps · B all lowercase · C lowercase with caps titles · D sentence case ·
E terminal lowercase): the user liked lowercase for most things, but buttons should stay
fully uppercase.

**Round 2, typeface**, with lowercase text and uppercase buttons (A JetBrains Mono · B IBM Plex
Mono · C Martian Mono · D Chakra Petch · E Space Grotesk with JetBrains Mono numbers).

**Verdict:** E. Built in `main` in "Text style: Space Grotesk words, mono numbers, lowercase
with uppercase buttons" (build 25).

Open `text-style.html` in a browser; ← → switch typeface, the top toggle switches screen.
