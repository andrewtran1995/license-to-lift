# Signing key

`license-to-lift.jks` signs every build, so a new APK installs over the old one and keeps your data.

It's committed on purpose. This is a personal, sideloaded app, and the repo is public, so anyone
with this key could build an APK that Android would accept as an update to yours. Only install
APKs from this repo's own Releases page.

Store and key password: `licensetolift`. Alias: `license-to-lift`.
